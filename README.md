# IgoAndTrack Desktop · Instaladores

Este repositorio contiene exclusivamente distribuciones binarias y manifiestos de verificación. El código fuente y los datos del PLC permanecen privados. Los MSI no tienen certificado Authenticode de Windows; las actualizaciones se verifican mediante manifiestos Ed25519.

Para instalarlo por primera vez, abre la [última versión](https://github.com/ShadowRosas/PLC-TT-Electronics-Releases/releases/latest), despliega **Assets** y descarga el archivo `IgoAndSeePLC-VERSION.msi`. Al instalarse aparece como **IgoAndTrack Desktop**. El nombre técnico del archivo MSI se conserva para que las computadoras con versiones anteriores puedan verificar y aplicar la actualización automática.
